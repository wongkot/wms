## 📦 Warehouse Management System (WMS)
Small web application for inventory management
- **Dashboard**: quick overview of key inventory metrics
- **Product**: manage product master data
- **Inventory**: manage and track inventory data across locations
- **History**: view inventory transactions

## 🚀 Live preview
Checkout the live preview version from [here](https://wongkot.github.io/wms/).

## ⚙️ Requirements (for development)
- Node.js (v22 or later)
- Angular CLI (v20.3.6 or later)

## 🔧 Setup
1. Download or clone the repo to your preferred directory.
2. Run the following command in the terminal window.
   ```c
   npm install
   ```
3. Start web application by running the command.
   ```c
   ng serve
   ```
4. Once the server is up and running, navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
